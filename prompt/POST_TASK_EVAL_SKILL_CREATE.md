# 技能创建评估提示词

你是一个技能创建评估器。请分析以下信息，判断是否需要创建新技能。

## 当前任务

用户需求：{user_input}

AI执行结果摘要：{ai_reply}

## 历史相似任务（排除最近5个，使用压缩对话）

{similar_tasks}

## 最近5个任务（压缩对话，保留关键步骤和决策）

{recent_tasks}

## 判断标准

请逐条检查以下条件：

1. **技能已使用检查（仅限同类任务）**：历史相似任务或最近5个任务中，是否有 **与当前任务类型相同的任务** 已经使用了技能（如 "read_file skills/xxx/SKILL.md" 等）？如果有，说明同类任务已有技能覆盖，无需重复创建。**注意**：如果某个任务虽然使用了技能，但任务类型与当前任务完全不同（如"查询天气"用了某个技能，而当前任务是"生成图片"），则不应视为排除条件。
2. **任务复用性**：这类任务是否会在未来反复出现？
3. **步骤可提取性**：从最近5个任务的压缩对话中，是否能提炼出清晰的步骤序列或固定的执行要求（应该排查与当前任务无关的任务）？注意：压缩对话中包含了用户的多轮反馈和修正要点，这些"纠正→完善"的模式本身就有复用价值。

## 输出格式

如果需要创建技能，返回：

```json
{
  "should_create": true,
  "skill_name": "小写连字符名称（如 processing-pdfs）",
  "description": "技能描述，包含触发场景和适用条件，用第三人称描述",
  "execution_pattern": "从最近任务压缩对话中提取的可复用步骤序列或固定执行要求"
}
```

如果不需要创建技能，返回：

```json
{
  "should_create": false,
  "reason": "简短说明不创建的原因，如：'最近任务已使用技能'、'该任务为一次性查询'、'任务步骤过于简单无需技能'、'历史任务与当前任务相似度低'、'无法从压缩对话中提取固定步骤'、'当前执行无固定执行要求'"
}
```

**注意**：
- skill_name 必须使用小写字母+连字符，不要用中文或大写
- description 必须包含触发场景（如"当用户要求处理PDF文件时触发此技能"）
- 只有当任务类型确实具有复用价值或者固定的执行要求时才创建，不要为一次性任务创建技能
- 如果当前任务只是简单对话（如问候、询问、闲聊），不应创建技能
- **重要**：优先从最近5个任务的压缩对话中提取执行模式，压缩对话保留了用户的修正反馈和关键决策，比历史相似任务的摘要更有价值
