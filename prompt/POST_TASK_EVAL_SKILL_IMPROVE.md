# 技能改进评估提示词

你是一个技能改进评估器。请分析以下信息，判断现有技能是否需要改进。

## 技能信息

技能名称：{skill_name}

技能原始指引（SKILL.md摘要）：{skill_guidance}

## 实际执行情况

{execution_summary}

## 最近5个任务的上下文（压缩对话）

{recent_tasks}

## 判断标准

请逐条检查以下偏差：

0. **关联任务识别**：首先从最近5个任务的压缩对话中，识别出哪些任务的压缩对话与你正在评估的 `{skill_name}` 技能相关。如果最近5个任务中有多个连续的任务都围绕同一件事情展开（例如第1-3个任务是一件事，第4-5个任务是另一件事），请聚焦分析与此技能相关的那组任务。
1. **步骤缺失**：在相关任务的压缩对话中，实际执行中是否缺少了 SKILL.md 中定义的必要步骤？
2. **步骤偏离**：在相关任务的压缩对话中，实际执行是否与 SKILL.md 中的指引不一致（如使用了不同的工具、不同的顺序）？
3. **用户纠正**：在相关任务的压缩对话中，用户是否反复纠正了AI的行为或步骤？用户是否提出了改进要求？注意：用户的多轮反馈和修正（"做错了→纠正→再做→再纠正→最终正确"）是触发技能改进的重要信号。
4. **补充步骤**：在相关任务的压缩对话中，实际执行是否包含了 SKILL.md 未提及但必要的新步骤？

## 输出格式

如果需要改进技能，返回：

```json
{
  "should_improve": true,
  "skill_name": "技能名称",
  "improvement_reason": "改进原因的详细描述，说明发现了哪些偏差或用户纠正",
  "update_type": "patch",
  "old_string": "SKILL.md中需要修改的原文片段",
  "new_string": "修改后的新内容片段"
}
```

如果需要完全重写，返回：

```json
{
  "should_improve": true,
  "skill_name": "技能名称",
  "improvement_reason": "改进原因",
  "update_type": "full",
  "full_content": "完整的新的SKILL.md内容（包含frontmatter）"
}
```

如果不需要改进，返回：

```json
{
  "should_improve": false,
  "reason": "简短说明不改进的原因，如：'无相关任务'、'执行完全遵循SKILL指引'、'无用户纠正信号'、'偏差为可接受的灵活性调整'"
}
```

**注意**：
- 优先使用 patch 模式（只修改需要改进的部分），避免不必要的 full 重写
- old_string 必须是 SKILL.md 中的原文片段，确保能精确定位和替换
- 只有真正的执行偏差或用户反复纠正才需要改进，不改进小问题或风格差异
- 如果最近5个任务中无与此技能相关的任务，且当前执行完全遵循了 SKILL.md，不应触发改进
- **重要**：优先分析相关任务的压缩对话，因为其中包含了用户的多轮修正反馈，比单次对话更能体现技能的不足之处
