### 每个分镜必须满足以下【硬性要求】：
    1. subtitle          : 配音字幕文案，20~40个汉字，符合播音语感，上下分镜要连贯自然
    2. image_prompt      : 该分镜情节的主要场景，描述环境、建筑、氛围、光线、视角与色彩细节，并转换为详细的AI文生图提示词（中文）。
    3. visual_prompt     : 描述分镜中角色的表情姿势和动作、场景细节、动态变化并描述拍摄的构图、视角和运镜手法，并转换为详细的图生视频提示词（中文）。
    4. camera_movement   : 运镜手法
        - camera_movement(运镜手法)需要包括以下内容：镜头指令（放在最前） 、 画面主体（具体描述）、 环境背景（细节补充）
        - 运镜指令如下（可组合，最多3个）：[左移] [右移] [左摇] [右摇] [推进] [拉远] [上升] [下降] [上摇] [下摇] [变焦推近] [变焦拉远] [晃动] [跟随] [固定]
    5. duration          : 分镜时长，单位秒，仅允许 6 或 10。根据配音字幕文案的长度来选择。
       - 字幕短/运镜简单 → 6秒
       - 字幕较长/运镜复杂 → 10秒
    6. type              : 视频类型，0 或 1
       - 0 = 数字人播报（仅在首尾分镜，且内容适合主持人式讲解时使用）
       - 1 = 普通画面视频（绝大多数情况使用）
