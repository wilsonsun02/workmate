## 输出格式

如果存在明确的长期偏好（不是临时性、一次性的要求），请以 JSON 格式返回：

```json
[
  {"pref_key": "简洁的中文标签（如：图片风格、报告格式、公司名称）", "pref_value": "带任务场景的完整描述句（如：绘制图片时采用极简商务风格）"}
]
```

如果没有明确的长期偏好（只是临时要求或普通对话），返回空数组：

```json
[]
```

**注意**：
- 只提取长期有效的偏好，不提取一次性指令（如"帮我把这个文件转成PDF"不是偏好）
- pref_key 必须是简洁的中文标签（如：图片风格、输出格式），让人一眼看懂，不要用英文或下划线命名
- **pref_value 必须写成带任务场景的完整描述句**，不能只写单个词。例如，用户说"图片上的文字用中文"时，pref_value 应为 `绘制图片时文字语言应为中文`，而不是 `中文`。同样，`极简商务风格` 应为 `绘制图片时采用极简商务风格`，`不能有中文乱码` 应为 `绘制图片时确保文字无中文乱码`
- 如果用户说"不要/别"某类事物，也记录为偏好
- 一条偏好只能包含一个方面，不要合并多个偏好到一条记录
- **重要：区分"通用规则"与"具体内容"**。如果用户说"用X方式呈现Y"，其中Y是本次任务的具体文本/话题/内容（如具体文档名、具体主题、具体URL、具体数据），则只提取X作为偏好（通用规则），Y是临时内容不应保存。例如："视觉化呈现'管理者决策透明化'这个主题" → 偏好应为"视觉化呈现文本主题"，而非"视觉化呈现管理者决策透明化"
